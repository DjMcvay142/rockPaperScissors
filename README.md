# Rock Paper Scissors

A classic Rock Paper Scissors game built with HTML, CSS, and JavaScript as part of my web development learning journey.

## 🎮 About The Project

This is a browser-based implementation of the classic hand game Rock Paper Scissors. Players compete against a computer opponent that makes random choices, with the game tracking scores across multiple rounds.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla)

## 🚀 Getting Started

### Playing the Game

1. Clone the repository:
   ```bash
   git clone https://github.com/DjMcvay142/rockPaperScissors.git
   ```

2. Navigate to the project directory:
   ```bash
   cd rockPaperScissors
   ```

3. Open `index.html` in your web browser

Alternatively, you can play the live version here: [Live Demo](#) *(add GitHub Pages link if deployed)*

## 🎯 How to Play

1. Choose your move: Rock, Paper, or Scissors
2. The computer will randomly select its move
3. The winner is determined by the classic rules:
   - Rock beats Scissors
   - Scissors beats Paper
   - Paper beats Rock
4. Keep track of your score and try to beat the computer!
